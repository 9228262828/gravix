Privacy Policy

GRAVIX — Core Escape
Package: com.gravix.coreescape
Effective date: September 5, 2026

Summary: The current core version of GRAVIX is an offline-first game. It requires no player account and stores gameplay progress locally. It does not currently include advertising, behavioral analytics, cross-app tracking, or a cloud gameplay database.

1. Introduction

This Privacy Policy explains how GRAVIX — Core Escape (“GRAVIX”, “the game”, “we”, “our”, or “us”) handles information when you use the mobile game. GRAVIX is designed as an offline-first game. This policy applies to the current version described here.

2. Information You Create Through Gameplay

GRAVIX can create gameplay records such as completed levels, stars earned, best completion times, collected energy cores, unlocked sectors, selected robot skin, and game settings. These records describe game progress and are not intended to identify you.

3. Local Storage

Gameplay progress and preferences are stored locally on your device using Flutter local storage technology, including SharedPreferences in the current core version. The game does not require a remote database to store your gameplay progress.

4. No Account Required

GRAVIX does not require you to register, sign in, create a username, or provide a password to play the current core version.

5. Progress Data

The game may locally save level completion status, star ratings, unlocked levels, best times, energy-core collection status, selected skins, sound preferences, and camera-shake preferences so your progress is available when you return.

6. Level Performance and Best Times

Completion times and level performance are calculated for gameplay features such as par-time challenges and star awards. In the current core version, these values remain on the device and are not sent to an online leaderboard.

7. Energy Cores and Stars

Energy cores, stars, unlocks, and similar gameplay rewards are virtual game-state values. They are stored locally and are used only to provide progression and gameplay features.

8. Robot Skins

Your selected robot skin and skin unlock status may be stored locally so the game can remember your customization.

9. Game Settings

Preferences such as sound being enabled or disabled and camera-shake settings may be saved locally.

10. No Advertising

The current core version of GRAVIX does not include advertising SDKs and does not use gameplay data to serve personalized advertisements.

11. No Behavioral Analytics

The current core version does not include a behavioral analytics service for profiling how you use the game.

12. No Cross-App Tracking

GRAVIX does not use the current core version to track you across other companies’ apps or websites for advertising or profiling.

13. No Sale of Personal Information

We do not sell or rent your personal information or gameplay records.

14. No Cloud Account or Cloud Sync

The current core version does not provide a GRAVIX cloud account or cloud synchronization for your game progress. If a future version introduces cloud features, this policy and applicable store disclosures should be updated before or when those features are released.

15. Internet Connection

Core gameplay is designed to work offline. The legal pages may be hosted publicly on GitHub Pages and require internet access when opened in a web browser. Future platform or distribution functionality may also involve network services outside the core game.

16. Device Permissions

The current core game is designed not to require sensitive device permissions for its gameplay. Any permission added in a future release should be requested only when needed for a clearly described feature.

17. Camera and Photos

The current core version does not require access to your camera or photo library for gameplay.

18. Microphone

The current core version does not require microphone access.

19. Contacts

The current core version does not require access to your contacts.

20. Precise Location

The current core version does not require precise or approximate device location for gameplay.

21. Files and Media

The current core version does not require broad access to your personal files or media to provide its normal gameplay features.

22. Advertising Identifier

The current core version does not use an advertising SDK to access an advertising identifier for personalized advertising.

23. Purchases

The current core version described by this policy does not rely on an account-based purchase system for its gameplay progress. If in-app purchases are added later, the policy and store disclosures should be reviewed and updated.

24. Notifications

The current core version does not need notification access for the gameplay described in this policy. If notifications are introduced later, the game should request any required permission according to platform rules.

25. Crash Reporting

The current core version does not intentionally integrate a third-party crash-reporting SDK. Operating systems and app distribution platforms may independently process diagnostic information according to their own settings and privacy policies.

26. Device Backups

Depending on your device and operating-system backup settings, locally stored app data may be included in device or cloud backups controlled by the operating-system provider. Those backup services are governed by the provider’s terms and privacy practices.

27. Data Retention

Locally stored game progress remains on the device until it is reset through available game controls, removed through device/app data controls, or removed when the app is uninstalled, subject to any device backup behavior.

28. Resetting Game Progress

GRAVIX includes a local progress reset function. Using it can remove saved stars, best times, unlocks, and related local progression information from the game’s active local storage.

29. Uninstalling the Game

Uninstalling GRAVIX generally removes locally stored application data from the device, subject to operating-system backup and restore features outside our direct control.

30. Security

Because core gameplay records are stored locally, we do not operate a remote gameplay database for that data in the current version. You should still protect access to your device using the security features available on your operating system.

31. Children’s Privacy

GRAVIX is a general-audience arcade game and does not intentionally ask players to submit personal information through the current core gameplay. If distribution requirements or future features change the game’s audience or data practices, this policy should be reviewed accordingly.

32. Third-Party Platforms

You may obtain GRAVIX through an app distribution platform, and the Privacy Policy itself may be hosted through GitHub Pages. Those third parties may process information independently under their own privacy policies. Their processing is not the same as GRAVIX collecting gameplay data.
